# Tabarka ملولة — نسخة تجريبية مجانية

## التشغيل
- افتح `index.html` مباشرة في المتصفح.
- للحصول على تجربة PWA والتثبيت على الهاتف، ارفع المجلد إلى استضافة HTTPS ثابتة (مثلاً GitHub Pages أو Cloudflare Pages) ثم افتح الرابط من الهاتف واختر Add to Home Screen.

## الموجود في النسخة
- واجهة عربية متجاوبة.
- صفحات: الرئيسية، اكتشف، خريطة توضيحية، طلبات الحجز، مساعد سياحي تجريبي، لوحة إدارة محلية.
- بحث وتصنيفات ومفضلة.
- حفظ طلبات الحجز والأماكن في LocalStorage على نفس الجهاز.
- تصدير طلبات الحجز إلى JSON.
- ملف manifest وservice worker كبداية لدعم PWA.

## حدود مهمة
- لا يوجد حالياً backend أو حسابات مستخدمين أو مزامنة بين الأجهزة.
- نموذج الحجز يحفظ طلباً محلياً فقط؛ لا يرسل الطلب إلى فندق ولا يؤكد أي حجز.
- المساعد يقدم ردوداً جاهزة وليس نموذج ذكاء اصطناعي متصلاً.
- الخريطة الحالية تخطيطية؛ روابط الاتجاهات تفتح بحث Google Maps. GPS والمسارات داخل التطبيق تحتاج مزود خرائط وربط API.
- الطقس المعروض ليس حياً بعد. يلزم مصدر طقس موثوق.
- الدفع الإلكتروني غير مفعّل. لا تجمع بيانات بطاقات الدفع في هذه النسخة.

## كيف تبقى مجانية؟
يمكن تشغيل النموذج محلياً مجاناً، واستضافته على خطة مجانية محدودة. خدمات AI والخرائط المتقدمة والرسائل والدفع قد تتطلب حسابات ومفاتيح API ورسوم استخدام. قبل الإطلاق الحقيقي أضف backend آمن، صلاحيات إدارة، سياسة خصوصية وشروط استخدام.
